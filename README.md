# OpenSubtitles

Два инструмента для тех, кто делает субтитры к YouTube-роликам (Windows):

- **YT Reaper** — качалка: вставил ссылку, нажал «Скачать». Видео в mp4 или звук в mp3, по желанию — субтитры с YouTube.
- **Sub Studio** — редактор субтитров в отдельном окне: распознавание речи, звуковая дорожка, стили и позиции как на YouTube, перевод, вшивание сабов в видео.

## Установка

1. [Python 3.10+](https://www.python.org/downloads/) (при установке отметь «Add to PATH»).
2. [ffmpeg](https://ffmpeg.org/download.html) в PATH — проще всего: `winget install ffmpeg`.
3. Зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Необязательно, если есть видеокарта NVIDIA, — распознавание станет в разы быстрее:
   ```
   pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12>=9,<10"
   ```

## Запуск

- `YT Reaper.bat` — качалка.
- `Sub Studio.bat` — редактор. Видео можно открыть кнопкой, из списка недавних/скачанных или просто перетащить в окно.

## Что умеет Sub Studio

- **Распознавание речи** (Whisper) — всего ролика или выделенного на дорожке участка. Модель скачивается один раз и заранее грузится в память.
- **Звуковая дорожка**: строки видны как блоки, их можно двигать и тянуть за края, зум — Ctrl+колесо.
- **Стили и позиции**: шрифты, цвета, обводка, плашка; строку можно перетащить мышкой прямо на видео.
- **Перевод** всех строк, пустых или участка, с глоссарием для имён и терминов.
- **Проверка**: слишком быстрый текст, длинные строки, наложения — с переходом к следующей проблеме.
- **Экспорт**: SRT (обычные субтитры) и YTT (формат YouTube со стилями и позициями).
- **Вшивание сабов в видео** (хардсаб) — всего ролика или пробного куска, на видеокарте NVIDIA или процессоре.
- **Горячие клавиши** работают на любой раскладке и настраиваются (F1). Держи Alt — подсказки появятся на кнопках.

Проект сохраняется сам — рядом с видео, в файл `<имя видео>.substudio.json`.

## Как загрузить субтитры на YouTube

YouTube Studio → **Субтитры** → нужный язык → **Добавить** → **Загрузить файл** → «С временными кодами». SRT подходит всегда, YTT — если нужны цвета и позиции.
